# Makeup Simulator

## Описание
Проект симулятора макияжа с использованием кистей, крема, помады и теней.

## Классы
- BlushHandler – наносит румяна
- ShadowEyeHandler – наносит тени
- PomadeHandler – наносит помаду
- CreamHandler – наносит крем/акне
- HandController – управление рукой и инструментами
- MakeupHandler – базовый класс для всех обработчиков

## Технические моменты
- Используется UniTask,  DOTween
